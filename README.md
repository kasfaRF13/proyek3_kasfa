# Refleksi Modul 1: Responsive Web Design & Semantic HTML

Sebagai mahasiswa D3 Teknik Informatika yang selama ini lebih banyak berfokus pada logika pemrograman dan arsitektur *backend*, mengerjakan tugas perbaikan halaman profil ini memberikan wawasan baru yang sangat berharga mengenai dunia *frontend* dan struktur antarmuka web. Ada beberapa poin pembelajaran utama yang saya dapatkan dari proses perbaikan kode HTML dan CSS ini.

Pertama, saya menyadari pentingnya penggunaan HTML Semantik dibandingkan sekadar menggunakan tag pembungkus generik seperti `<div>`. Dalam perbaikan kode ini, saya mengganti struktur lama dengan elemen yang lebih bermakna seperti `<header>`, `<main>`, `<section>`, dan `<footer>`. Perubahan ini bukan hanya membuat susunan kode menjadi lebih rapi dan mudah dibaca oleh sesama *developer*, tetapi juga memiliki peran krusial dalam aksesibilitas. Teknologi pembaca layar (*screen reader*) sangat bergantung pada elemen semantik ini untuk memandu pengguna dengan kebutuhan khusus dalam menavigasi bagian-bagian penting dari sebuah situs web.
